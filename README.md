# end-to-end-time-series-forecasting
An end-to-end time series forecasting project using the Walmart Recruiting dataset, covering EDA, feature engineering, model development, evaluation, and forecasting with Python.

# Dataset

This project uses the **Walmart Recruiting - Store Sales Forecasting** dataset from Kaggle.

The dataset is not included in this repository due to Kaggle's competition terms.

Download it here:

https://www.kaggle.com/competitions/walmart-recruiting-store-sales-forecasting

Place the following files in this folder:

- train.csv
- stores.csv
- features.csv
